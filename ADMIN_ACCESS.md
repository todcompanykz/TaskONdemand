# Доступ к админ-панели

## Как получить доступ к админ-панели

Для доступа к админ-панели необходимо зарегистрироваться с email, который соответствует одному из критериев:

1. **Email содержит "@admin."** (например: `user@admin.tod.kz`)
2. **Email начинается с "admin@"** (например: `admin@tod.kz`)
3. **Email в списке админов:**
   - `admin@tod.kz`
   - `admin@example.com`

## Примеры админских email:

✅ **Работают:**
- `admin@tod.kz`
- `admin@example.com`
- `user@admin.tod.kz`
- `admin@anydomain.com` password:admin22

❌ **Не работают:**
- `user@tod.kz`
- `test@example.com`
- `adminuser@tod.kz` (должно быть `admin@` в начале)

## Как зайти в админ-панель:

1. Зарегистрируйтесь с одним из админских email (см. выше)
2. Войдите в систему
3. В навигационном меню появится ссылка **"Админ"**
4. Или перейдите напрямую: http://localhost:3000/admin

## Функции админ-панели:

- **Статистика**: Просмотр количества пользователей и задач
- **Пользователи**: Список всех зарегистрированных пользователей
- **Задачи**: Просмотр всех задач с возможностью удаления

## Изменение списка админов:

Чтобы добавить или изменить список админов, отредактируйте файл:
`apps/backend/src/admin/guards/admin.guard.ts`

Добавьте email в массив `adminEmails` или измените логику проверки.
