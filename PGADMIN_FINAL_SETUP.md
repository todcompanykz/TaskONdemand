## 📋 Параметры подключения в pgAdmin:

### Основные параметры:
- **Host name/address:** `127.0.0.1` (обязательно используйте IP, не localhost)
- **Port:** `5432`
- **Maintenance database:** `postgres` (для первого подключения)
- **Username:** `postgres`
- **Password:** `postgres`
- ✅ **Save password:** включите галочку

### Вкладка "SSL":
- **SSL mode:** `disable` или `prefer`

### pg_hba.conf:
```
host    all             all             127.0.0.1/32            md5
host    all             all             ::1/128                 md5
host    all             all             0.0.0.0/0               md5
```

### password_encryption:
```
md5
```

## 🧪 Проверка подключения:

Если подключение всё ещё не работает, выполните проверку:

```bash
# Проверить статус контейнера
docker compose ps postgres

# Проверить логи
docker compose logs postgres --tail 20

# Проверить подключение из контейнера
docker compose exec postgres psql -U postgres -d tod -c "SELECT version();"
```

## ⚠️ Важные замечания:

1. **Используйте `127.0.0.1` вместо `localhost`** - это может решить проблемы с разрешением DNS
2. **SSL mode должен быть `disable` или `prefer`** - не используйте `require` без настройки SSL
3. **Убедитесь, что порт 5432 не заблокирован файрволом**
4. **Перезапустите pgAdmin** после изменения настроек подключения

## 🔄 Если проблема сохраняется:

1. Удалите существующее подключение в pgAdmin
2. Создайте новое подключение с нуля
3. Используйте точно эти параметры:
   - Host: `127.0.0.1`
   - Port: `5432`
   - Database: `postgres`
   - Username: `postgres`
   - Password: `postgres`
   - SSL mode: `disable`

## 📝 Альтернативные клиенты:
