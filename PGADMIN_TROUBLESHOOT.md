# Устранение проблем подключения pgAdmin

## Текущая ситуация

Конфигурация PostgreSQL настроена правильно:
- ✅ Порт 5432 открыт и доступен
- ✅ pg_hba.conf настроен для trust на 127.0.0.1
- ✅ PostgreSQL слушает на всех интерфейсах

## Попробуйте следующие шаги:

### 1. Удалите старое подключение в pgAdmin
- Правой кнопкой на сервере → "Delete Server"
- Подтвердите удаление

### 2. Создайте новое подключение с нуля
- Правой кнопкой на "Servers" → "Create" → "Server..."

### 3. Параметры подключения (ОБЯЗАТЕЛЬНО используйте эти значения):

**Вкладка "General":**
- Name: `PostgreSQL 18`

**Вкладка "Connection":**
- Host name/address: `127.0.0.1` (НЕ localhost!)
- Port: `5432`
- Maintenance database: `postgres`
- Username: `postgres`
- Password: `postgres` (можно оставить пустым, так как используется trust)
- ✅ Save password: включите

**Вкладка "SSL":**
- SSL mode: `disable`

### 4. Если не работает, попробуйте IPv6
- Host name/address: `::1`

### 5. Проверьте логи PostgreSQL при попытке подключения

Откройте терминал и выполните:
```bash
docker compose logs -f postgres
```

Затем попробуйте подключиться в pgAdmin и посмотрите, какие сообщения появляются в логах.

### 6. Альтернативный способ - используйте DBeaver

Если pgAdmin продолжает вызывать проблемы, установите DBeaver:
- Скачайте с https://dbeaver.io/
- Создайте новое подключение PostgreSQL
- Используйте те же параметры

### 7. Проверка через командную строку

Проверьте, что подключение работает из командной строки:
```bash
docker compose exec postgres psql -U postgres -d tod -c "SELECT version();"
```

Если эта команда работает, значит PostgreSQL настроен правильно.

## Возможные причины проблемы:

1. **Кэш pgAdmin** - перезапустите pgAdmin полностью
2. **IPv6 vs IPv4** - попробуйте использовать `::1` вместо `127.0.0.1`
3. **Файрвол Windows** - проверьте, что порт 5432 не заблокирован
4. **Антивирус** - может блокировать подключения к localhost

## Следующие шаги для диагностики:

1. Попробуйте подключиться снова с параметрами выше
2. Если не работает, откройте логи PostgreSQL в реальном времени:
   ```bash
   docker compose logs -f postgres
   ```
3. Попробуйте подключиться в pgAdmin
4. Скопируйте сообщения из логов, которые появляются при попытке подключения
5. Отправьте эти логи для дальнейшей диагностики
