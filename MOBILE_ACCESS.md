# Инструкция по подключению с телефона

Эта инструкция поможет вам открыть приложение Task on Demand на вашем телефоне через локальную сеть.

## Предварительные требования

1. Компьютер и телефон должны быть подключены к **одной Wi-Fi сети**
2. Docker и Docker Compose должны быть запущены на компьютере
3. Приложение должно быть запущено (`docker compose up`)

## Шаг 1: Узнайте IP-адрес вашего компьютера

### Windows:
1. Откройте командную строку (CMD) или PowerShell
2. Выполните команду: `ipconfig`
3. Найдите раздел с вашим Wi-Fi адаптером (обычно "Беспроводной LAN адаптер Wi-Fi" или "Wireless LAN adapter Wi-Fi")
4. Найдите строку **IPv4-адрес** (например: `192.168.1.100`)

### Альтернативный способ (Windows):
- Нажмите `Win + R`
- Введите `cmd` и нажмите Enter
- Выполните: `ipconfig | findstr IPv4`

## Шаг 2: Проверьте, что приложение запущено

Выполните на компьютере:
```bash
docker compose ps
```

Убедитесь, что контейнеры `tod-frontend` и `tod-backend` имеют статус `Up`.

## Шаг 3: Откройте приложение на телефоне

**По умолчанию всё работает автоматически!** Просто введите IP-адрес в браузере.

1. Убедитесь, что телефон подключен к той же Wi-Fi сети, что и компьютер
2. Откройте браузер на телефоне (Chrome, Safari, Firefox и т.д.)
3. Введите в адресной строке:

```
http://[IP-АДРЕС-КОМПЬЮТЕРА]:3000
```

**Пример:**
```
http://192.168.1.100:3000
```

Замените `192.168.1.100` на IP-адрес вашего компьютера из Шага 1.

### Альтернатива: Явная настройка через .env файл

Если вы хотите явно указать API URL (например, для использования другого порта или домена), создайте файл `.env` в корне проекта и добавьте:

```env
NEXT_PUBLIC_API_URL=http://[IP-АДРЕС]:3001
```

**Пример:**
```env
NEXT_PUBLIC_API_URL=http://192.168.1.100:3001
```

После создания или изменения `.env` файла:
1. Пересоберите frontend: `docker compose build frontend`
2. Перезапустите frontend: `docker compose restart frontend`

**Примечание:** Если `NEXT_PUBLIC_API_URL` задан в `.env`, он будет использован вместо автоматического определения. Если не задан - будет использовано автоматическое определение на основе IP-адреса из браузера.

## Шаг 4: Разрешите доступ через брандмауэр (если не открывается)

Если страница не открывается, возможно, нужно разрешить доступ через брандмауэр Windows:

### Windows Firewall:
1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Выберите "Правила для входящих подключений" → "Создать правило"
4. Выберите "Порт" → "TCP" → "Определенные локальные порты": `3000, 3001`
5. Разрешите подключение
6. Примените правило для всех профилей

### Или через PowerShell (от имени администратора):
```powershell
New-NetFirewallRule -DisplayName "Task on Demand Frontend" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
New-NetFirewallRule -DisplayName "Task on Demand Backend" -Direction Inbound -LocalPort 3001 -Protocol TCP -Action Allow
```

## Шаг 5: Проверка подключения

После открытия приложения на телефоне вы должны увидеть:
- Страницу входа или ленту задач (если уже авторизованы)
- Все функции должны работать так же, как на компьютере

## Устранение проблем

### Проблема: Страница не открывается
- ✅ Убедитесь, что компьютер и телефон в одной Wi-Fi сети
- ✅ Проверьте, что IP-адрес правильный
- ✅ Проверьте, что порты 3000 и 3001 открыты в брандмауэре
- ✅ Убедитесь, что Docker контейнеры запущены

### Проблема: Ошибка подключения к API
- ✅ Backend должен быть доступен по адресу `http://[IP]:3001`
- ✅ По умолчанию API URL определяется автоматически на основе IP-адреса, который вы ввели в браузере
- ✅ Если используете `.env` файл, убедитесь, что `NEXT_PUBLIC_API_URL` указан правильно
- ✅ После изменения `.env` пересоберите и перезапустите frontend: `docker compose build frontend && docker compose restart frontend`
- ✅ Если всё ещё не работает, проверьте, что backend отвечает: откройте `http://[IP]:3001/health` в браузере
- ✅ Убедитесь, что порт 3001 открыт в брандмауэре (см. Шаг 4)

### Проблема: Медленная загрузка
- ✅ Это нормально для локальной сети
- ✅ Убедитесь, что Wi-Fi сигнал достаточно сильный

## Быстрый доступ

Сохраните закладку в браузере телефона для быстрого доступа:
- Название: "Task on Demand"
- URL: `http://[ВАШ-IP]:3000`

## Примечания

- IP-адрес может измениться при переподключении к Wi-Fi
- Если IP изменился, обновите закладку
- Для постоянного IP-адреса настройте статический IP в настройках роутера

## Полезные команды

```bash
ipconfig | findstr IPv4
```

