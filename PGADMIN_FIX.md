# Исправление проблемы подключения pgAdmin к PostgreSQL

## Проблема
Ошибка: "connection failed: connection to server at "::1", port 5432 failed: подключение "postgres" не разрешено в файле конфигурации"

## Решение

### 1. Настройка pg_hba.conf выполнена

Конфигурация `pg_hba.conf` была обновлена для разрешения подключений через `md5` аутентификацию.

### 2. Параметры подключения в pgAdmin

Используйте следующие параметры:

- **Host name/address:** `localhost` или `127.0.0.1`
- **Port:** `5432`
- **Maintenance database:** `postgres` (для первого подключения)
- **Username:** `postgres`
- **Password:** `postgres`
- ✅ **Save password:** включите

### 3. Если подключение всё ещё не работает

Попробуйте следующие шаги:

#### Вариант 1: Использовать IP адрес вместо localhost
- **Host name/address:** `127.0.0.1` (вместо `localhost`)

#### Вариант 2: Проверить настройки SSL
- Вкладка **"SSL"** в pgAdmin:
  - **SSL mode:** `prefer` или `disable`

#### Вариант 3: Перезапустить PostgreSQL
```bash
docker compose restart postgres
```

#### Вариант 4: Проверить, что порт открыт
```bash
docker compose port postgres 5432
```

Должно вернуть: `0.0.0.0:5432`

### 4. Проверка подключения через командную строку

Проверьте, что подключение работает из командной строки:

```bash
docker compose exec postgres psql -U postgres -d tod -c "SELECT version();"
```

Если эта команда работает, значит PostgreSQL настроен правильно, и проблема может быть в настройках pgAdmin.

### 5. Альтернатива: Использовать DBeaver или другой клиент

Если pgAdmin продолжает вызывать проблемы, можно использовать:
- **DBeaver** (бесплатный, кроссплатформенный)
- **DataGrip** (платный, от JetBrains)
- **psql** (командная строка)

### 6. Текущая конфигурация pg_hba.conf

Текущие настройки разрешают подключения:
- `127.0.0.1/32` - через `md5`
- `::1/128` - через `md5` (IPv6)
- `0.0.0.0/0` - через `md5` (любой IP)

Все подключения используют метод аутентификации `md5`, который требует пароль.

### 7. Если нужно изменить пароль

```bash
docker compose exec postgres psql -U postgres -c "ALTER USER postgres WITH PASSWORD 'ваш_новый_пароль';"
```

Затем обновите пароль в настройках подключения pgAdmin.
